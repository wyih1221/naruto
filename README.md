# NARUTO · 忍界

一个火影忍者主题的单页网站，用来练习 Git / GitHub 工作流。

暗色「木叶 + 橙色查克拉」风格，全部视觉由 CSS 与 SVG 手工绘制，**零外部图片依赖**，断网也不会掉图。

## 内容

- 开场结印动画（SVG 描边绘制）
- 首屏渐变标题 + 纯 CSS 螺旋丸（三层圆锥渐变反向旋转）
- 6 张忍者卡，含手绘 SVG 写轮眼（悬停加速旋转）
- 打字机效果的名言带
- 6 个忍术卡 + 查克拉充能条
- 世纪年表、数字计数器

## 交互与彩蛋

| 操作 | 效果 |
| --- | --- |
| 滚动 | 各区块逐项淡入、导航高亮、顶部进度条 |
| 悬停卡片 | 3D 倾斜 + 光斑跟随鼠标 |
| 点击螺旋丸 | 球体挤压回弹，炸开汉字粒子 |
| 按 `K` | 施展影分身之术 |

## 技术

纯 HTML / CSS / JavaScript 单文件，无构建步骤、无依赖。

- 粒子：Canvas + requestAnimationFrame
- 动效：IntersectionObserver + CSS transition
- 字体：Bebas Neue / Noto Serif JP（Google Fonts，断网自动回落系统字体）

## 本地运行

直接用浏览器打开 `naruto.html` 即可。
